# Sahay - Smart Micro-Cold Storage for Smallholder Farmers

A high-converting, accessible, and responsive landing page for **Sahay**, an IoT-enabled micro-cold storage kit designed for smallholder farmers to reduce post-harvest crop loss.

---

## 🌾 Overview

Over 40% of fresh produce spoils before reaching the market due to lack of accessible cold storage. Conventional cold chain infrastructure is expensive, energy-intensive, and out of reach for smallholder farmers.

**Sahay** bridges this gap with an affordable, solar-compatible, plug-and-play micro-cold storage unit that prolongs produce shelf-life from 2 days to over 21 days.

---

## ✨ Features

- **Modern & Dynamic UI**: Built with accessible semantic HTML5, fluid responsive CSS design, glassmorphic accents, and micro-interactions.
- **Visual Kit Breakdown**: Exploded-view component anatomy showcasing IoT sensors, solar charging, thermoelectric cooling, and phase-change insulation.
- **ROI & Savings Calculator**: Interactive tool helping farmers and cooperatives calculate expected loss reduction and payback periods.
- **Social Proof & Testimonials**: Real-world field test accounts with metrics and verified case studies.
- **Interactive FAQ Accordion**: Expandable answers to common questions regarding power requirements, crop compatibility, and maintenance.
- **Lead Capture Form**: Client-side validated signup for pilot programs, subsidies, and distributor inquiries.
- **Zero-Dependency & Fast Load**: 100% vanilla HTML, CSS, and JavaScript. Super fast TTFB and Lighthouse scores.

## 🚀 Live Demo & Deployment

This project is ready to deploy on **Vercel** with zero build configuration.

### Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/vaibhavsingh02001-cyber/Sahay_.git)

1. Connect your GitHub account to [Vercel](https://vercel.com).
2. Click **Add New Project** and import the `Sahay_` repository.
3. Keep the default settings (Framework Preset: *Other*, Root Directory: `./`).
4. Click **Deploy**.

## 🛠️ Local Development

To run the site locally without any build tools:

```bash
# Using Python
python -m http.server 3000

# Or using npx serve
npx serve .
```

Open `http://localhost:3000` in your browser.
